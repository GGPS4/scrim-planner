# Scrim Planner

**Live site: [ggps4.github.io/scrim-planner](https://ggps4.github.io/scrim-planner/)**

Points tracker and practice planner for the Binghamton Video Game Association **Fortnite A team**, which plays ECAC Fortnite Builds (Duos).

- Log each Thursday match night: placement and eliminations for all 4 matches
- Points are calculated with the ECAC Fall 2026 Fortnite Builds (Duos) scoring: 65 points for 1st down to 2 for 25th, plus 2 points per elimination in the regular season (4 in playoffs, with a 1.5x multiplier in Finals week 2)
- Tracks season points, total eliminations and average placement (the ECAC tiebreakers)
- Team week: ECAC match night Thursdays 8–10 PM, practice Saturdays 6–8 PM
- Duo roster (2 to 4 players), drop and rotation plans, and JSON export/import

Data is saved in your browser. Scoring source: [ECAC Rulebook, Fall 2026](https://docs.google.com/document/d/1aXvTEiqAGykPtmmCtJYLim-HduXbVIrSaARWc6pR52U/edit).
